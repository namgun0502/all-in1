# 제니트리 스카이블루 투명 배경 PWA 앱 아이콘 적용 계획서

## 1. 개요 및 목적
- **목적**: 앱 아이콘의 검정색 원형 배경을 제니트리 공식 스카이블루(`#0284C7`)로 변경하고, 원형 바깥쪽 영역을 100% 투명(Transparent)하게 처리하여 모바일 홈 화면 및 PC 바탕화면에서 원형 심볼이 깔끔하게 표시되도록 개선합니다.
- **적용 대상**:
  - `public/brand/logo/icon-janytree.svg` (배경 사각형 제거, 투명 알파 채널 적용, 원형 `#0284C7`)
  - `public/brand/logo/icon-192.png` (192x192 투명 PNG)
  - `public/brand/logo/icon-512.png` (512x512 투명 PNG)
  - `public/sw.js` (캐시 버전 v5 업그레이드)

## 2. 세부 명세
- **원형 배경 색상**: 제니트리 브랜드 공식 스카이블루 (`#0284C7`)
- **원형 바깥 영역**: 투명 알파(Alpha 0, 투명도 100%)
- **내부 심볼**: 순백색 (`#FFFFFF`) `J+` 마크 중앙 유지
