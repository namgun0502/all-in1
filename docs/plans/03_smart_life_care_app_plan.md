# 03_스마트 라이프 소모품 케어 앱 구축 및 제니트리 디자인 적용 계획서

남건, '스마트 라이프 소모품 케어 AI 어시스턴트' 기능을 웹 애플리케이션으로 구현하고, **제니트리 디자인 시스템(JT Master v3.0)**을 적용하며 **GitHub + Cloudflare Pages 자동 배포** 환경에 맞추기 위한 개발 계획서입니다.

---

## 1. 프로젝트 목표 및 개요
1. **서비스 목적**:
   - 차량, 가전제품, IT 기기, 생필품 등 모든 자산과 소모품의 수명 및 교체 주기를 AI 분석 알고리즘과 대시보드로 관리
   - 교체 시기 지연 시 위험 요소 안내 및 사용자 맞춤형 관리 팁 제공
2. **디자인 시스템**:
   - 사내 `JT_디자인시스템_MASTER_v3.0.md` 기준 준수
   - 색상 체계: Primary Charcoal (`#1F2328`), Accent Blue (`#305CDE`), Success (`#14A870`), Warning (`#F0B01C`), Error (`#E14B4B`)
   - 폰트: Pretendard 웹폰트 및 Figtree 숫자 스택
   - 레이아웃: 신뢰성 있고 단정한 제니트리 특유의 카드/그리드/배지 스타일
3. **배포 및 인프라**:
   - Next.js 15 App Router 기반
   - OpenNext + Cloudflare Pages 환경 (GitHub 연동 Push 시 자동 배포)
   - 별도 복잡한 서버 설정 없이 즉시 동작할 수 있도록 브라우저 로컬 저장소(LocalStorage) 및 브라우저 내 AI 분석 엔진 우선 구현

---

## 2. 세부 기능 구성

### [화면 1] 제니트리 스타일 탑 내비게이션 & 통계 요약 바 (Summary KPI)
- 전체 관리 중인 소모품 개수
- 양호(GOOD), 주의(CAUTION), 즉시 교체 필요(REPLACE_NOW) 항목 통계 카드
- 제니트리 심볼 및 "스마트 라이프 소모품 케어" 브랜드 타이틀

### [화면 2] AI 스마트 분석 & 신규 소모품 등록 폼
- **간편 입력 및 이미지 라벨 텍스트 분석 시뮬레이션**:
  - 제품명 (예: 아반떼 CN7 엔진오일, 공기청정기 필터, 칫솔 등)
  - 카테고리 선택: 차량 / 가전 / IT기기 / 생필품·기타
  - 사용 시작일/교체일 및 현재 사용량/주행거리
  - 사용 환경/빈도 (일반 조건 / 가혹 조건)
- **AI 분석 버튼**:
  - 표준 주기 DB 및 조건 기반 남은 수명(%), 추천 교체일, 위험 요소, 관리 팁 자동 산출
  - 이전 정의된 JSON 스키마를 100% 만족하는 구조화된 결과 생성

### [화면 3] 소모품 목록 및 인터랙티브 상태 카드 (Asset Grid)
- 각 자산별 남은 수명 프로그레스 바 (제니트리 색상: 녹색/노란색/빨간색)
- 상태 배지 (`GOOD`, `CAUTION`, `REPLACE_NOW`)
- 남은 수명, 다음 교체 예정일, 교체 지연 시 위험 경고 토글 모달/드로어
- 삭제 및 교체 완료(리셋) 기능

---

## 3. 구현 단계 (Step-by-Step)

- **Step 1**: 제니트리 디자인 시스템 글로벌 CSS (`app/globals.css`) 구축
  - Pretendard 폰트 로드
  - 디자인 토큰 CSS 변수 선언 (Primary, Accent, Status Colors, Shadows, Radius)
- **Step 2**: 소모품 데이터 모델 및 AI 분석 엔진 로직 작성 (`app/types.ts`, `app/lib/care-ai.ts`)
  - 차량(엔진오일, 에어컨필터, 브레이크패드, 타이어), 가전(공기청정기, 정수기), IT기기, 생필품 표준 데이터베이스 내장
- **Step 3**: 메인 대시보드 컴포넌트 개발 (`app/page.tsx`, `app/layout.tsx`)
  - 제니트리 테마에 맞춘 직관적인 UI 완성
- **Step 4**: Cloudflare 빌드 검증 (`npm run cf:build`)
- **Step 5**: GitHub Commit & Push 및 Cloudflare Pages 연동 가이드 안내
