# 04_제조사(회사)별 맞춤형 주기 케어 추천 기능 기획서

남건, 질문해주신 **"회사(제조사/브랜드)별로 소모품 교체 주기를 다르게 추천할 수 있는가"**에 대한 맞춤형 추천 로직 기획서입니다.

## 2. 회사별 맞춤 추천 시스템 구현 방식

1. **회사(제조사) 선택/입력 필드 제공**:
   - 사용자가 품목 등록 시 제조사(예: 현대, 기아, 벤츠, BMW, 테슬라, LG전자, 삼성전자, 다이슨, 애플 등)를 선택하거나 직접 입력할 수 있습니다.
2. **제조사별 프리셋 데이터베이스 탑재**:
   - 제조사 공식 매뉴얼에 명시된 고유 권장 주기(거리, 기간, 사용 시간)와 가혹 조건 관리 지침을 기본 데이터로 내장합니다.
3. **지능형 자동 추정 (폴백 Fallback)**:
   - 만약 사용자가 회사를 모르는 중소기업 제품이나 미등록 브랜드 제품을 입력할 경우, 안전한 **"산업 표준 권장 주기"**를 적용하고 `[표준 추정치]` 표시를 띄워줍니다.
4. **위험 요소 및 팁도 회사별 맞춤 안내**:
   - 예: BMW 차량은 롱라이프 규격 오일 사용 팁 제공, LG 공기청정기는 프리필터 물세척 주기 함께 안내 등.

## 3. 제니트리 UI 반영
- 소모품 등록 모달에 **'제조사(회사)'** 선택 드롭다운 및 직접 입력란 배치
- 카드 상세 보기에서 **"[LG전자 공식 기준]"**, **"[현대자동차 매뉴얼 기준]"**과 같은 인증 배지를 제니트리 스타일로 세련되게 표시
