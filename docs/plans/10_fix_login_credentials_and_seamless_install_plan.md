# 10_fix_login_credentials_and_seamless_install_plan.md

남건, 요청하신 **"[로그인 실패] Invalid login credentials 해결"**과 **"이런저런 절차 없이 버튼 누르면 바로 설치되도록 개선"**을 위한 구현 계획서입니다.

---

## 1. 문제 분석 및 개선 대책

### 1) [로그인 실패] Invalid login credentials 원인 및 해결
- **발생 원인**:
  - `Invalid login credentials`는 Supabase Auth에서 **"가입되지 않은 이메일이거나 비밀번호가 일치하지 않을 때"** 발생하는 표준 영문 오류입니다.
  - 이전에 회원가입하지 않은 상태에서 바로 로그인을 시도하셨거나, 비밀번호가 다를 때 친절한 한국어 안내 없이 영문 에러 메시지가 그대로 출력되어 혼란이 발생했습니다.
- **해결 조치 (`app/lib/auth.ts`, `app/page.tsx`)**:
  - `Invalid login credentials` 발생 시: **"가입되지 않은 이메일이거나 비밀번호가 올바르지 않습니다. 먼저 '회원가입하기' 버튼을 눌러 계정을 생성해 주세요."**라는 명확하고 친절한 한글 문구로 즉시 변환.
  - 로그인 폼에 **[원클릭 회원가입으로 전환]** 버튼을 에러 창 바로 아래에 제공하여 초보자도 1초 만에 가입 후 로그인할 수 있도록 UX 개선.

### 2) 앱 설치 시 이런저런 절차(가이드 팝업) 거치지 않고 바로 설치되게 개선
- **발생 원인**:
  - 브라우저의 PWA 설치 이벤트(`beforeinstallprompt`)가 발동하기 전이나, 브라우저 정책(Chrome 주소창 설치 버튼 우선 등)으로 인해 이벤트 객체가 대기 상태일 때, 기존 코드가 긴 가이드 팝업 모달을 띄워 번거로움을 주었습니다.
- **해결 조치 (`public/manifest.json`, `app/page.tsx`)**:
  - `manifest.json`에 PWA 최신 필수 표준 속성(`id: "/"`, `scope: "/"`, `prefer_related_applications: false`)을 보강하여 브라우저가 첫 접속 0.1초 만에 설치 준비를 끝내도록 최적화.
  - **설치 버튼 클릭 시 가이드 모달 없이 즉시 브라우저 시스템 설치 프롬프트 발동**:
    - `deferredPrompt`가 있으면 즉시 시스템 설치 팝업(`prompt()`) 호출.
    - 브라우저에 이미 설치 아이콘이 준비되어 있는 경우, 긴 모달 대신 화면 상단에 깔끔한 **토스트 팁("주소창 우측 [설치] 버튼을 누르시면 1초 만에 설치됩니다")**만 띄우고 불필요한 단계 창을 전면 제거.
