# 06_제니트리 정품 공식 로고 탑재, 이메일 회원가입/로그인 및 PWA 앱 설치 기능 계획서

남건, 요청하신 **"진짜 제니트리 공식 로고(정품 SVG) 탑재"**, **"이메일 회원가입 및 로그인(Auth) 시스템"**, 그리고 **"앱 설치(PWA) 버튼"** 구현 계획서입니다.

---

## 1. 개요 및 요구사항 분석

### 1) 제니트리 진짜 공식 로고(정품 SVG) 자산 탑재
- 사용자 PC 내 실제 제니트리 브랜드 폴더에 보관된 **정품 공식 벡터 SVG 파일(`logo-h.svg`, `logo-h-light.svg`, `logo-v.svg` 등)**을 프로젝트 `public/brand/logo/`로 정식 투입합니다.
- 임의 제작된 로고 대신, 제니트리 고유의 정품 타이포그래피와 심볼 마크를 100% 원본 그대로 화면 상단바와 로그인 카드에 적용합니다.

### 2) 이메일 회원가입 / 로그인 시스템 (사용자별 소모품 데이터 격리)
- **제니트리 디자인 가이드라인 §8 Auth 규격 적용**:
  - 화면 중앙 제니트리 인증 카드 (정품 로고 + 이메일/비밀번호 폼)
  - 이메일 회원가입 및 로그인 토글 탭
- **보안 및 암호화 (규칙 8 준수)**:
  - 비밀번호 단방향 해싱(SHA-256) 처리 후 저장
  - 가입자 이메일 계정별로 각자의 소모품 데이터가 안전하게 격리 저장
  - 로그인 상태 유지 및 상단바 사용자 이메일 표시, 원클릭 로그아웃 지원

### 3) 앱 설치(PWA) 가능 버튼 탑재
- **로그인 폼 바로 아래 및 메인 화면**에 **"📲 스마트폰 / PC에 앱 설치하기"** 버튼 배치
- PWA 웹앱 매니페스트(`public/manifest.json`) 및 서비스 워커 환경 구성
- 모바일(안드로이드/크롬 등) 및 데스크톱에서 실제 독립 실행형 앱(PWA)으로 1초 만에 설치할 수 있도록 브라우저 설치 프로그래밍 연동(`beforeinstallprompt`)
- 아이폰(Safari) 사용자를 위한 '홈 화면에 추가' 가이드 모달 제공

---

## 2. 작업 단계 (Step-by-Step)

- **Step 1**: 진짜 제니트리 공식 로고 SVG 파일 복사 (`public/brand/logo/`) 및 `ZenitreeLogo.tsx`를 정품 SVG 연동으로 교체
- **Step 2**: PWA 웹앱 매니페스트(`public/manifest.json`) 생성 및 `app/layout.tsx` 메타태그 등록
- **Step 3**: 사용자 인증 모듈(`app/lib/auth.ts`) 구현 (SHA-256 암호화 및 계정 관리)
- **Step 4**: 로그인/회원가입 화면 및 "앱 설치하기" 버튼 UI 통합 (`app/page.tsx`)
- **Step 5**: Cloudflare 빌드 검증 (`npm run cf:build`)
